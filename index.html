Вот полный HTML-файл для веб-приложения (Telegram Web App), которое работает как финансовый трекер с управлением по месяцам, категориями и копилкой. ```html Финансовый трекер — Копилка и бюджет
Январь
💰 Баланс месяца (доходы − траты)
0 ₽
🐷 НАКОПЛЕНИЯ (копилка) 0 ₽
📋 Категории трат
⚡ При пополнении (зарплата/пенсия/аванс): сумма распределяется по категориям трат (вычитается из дохода),
остаток автоматически уходит в копилку. Редактируйте суммы категорий, они влияют на баланс и копилку!
```
